## MathPrime 1.9.0

Install with `MathPrime-1.9.0-setup.exe`, or from MathPrime 1.8 with Help → Check for updates → Download and install.
Your worksheets and settings are kept. Without installing: unzip and start `mathprime.exe`.

### Calculating
- **Tolerances and error propagation**: `L := 2 m ± 1 mm`. Independent sources add in quadrature; the same source
  cancels, so `L - L` is exactly 0. `nomval` and `unc` give the value and the uncertainty separately.
- **Lookup tables**: `IPE := tabel("IPE")`, then `IPE("IPE200").Iy`. IPE, HEA and HEB profiles (properties calculated
  from the geometry and tested against published tables), bolts, bolt classes, materials and concrete.
- **Functions**: `Jacob`, elliptic integrals (`ellipK`, `ellipE`, `ellipF`, `ellipPi`), `supsmooth`.

### Plots
- **3D curves**: `plot t = 0 ; 20 : cos(t), sin(t), t | 3d` (drag rotates).
- **Vector fields**: `plot x = -2 ; 2, y = -2 ; 2 : -y, x | field`.
