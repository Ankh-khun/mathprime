## MathPrime 1.6.0

Installeer met `MathPrime-1.6.0-setup.exe` (sluit MathPrime eerst; je werkbladen en instellingen blijven staan).
Zonder installatie: pak de zip uit en start `mathprime.exe`.

### Nieuw

- **Stelsels differentiaalvergelijkingen** met odesolve, zoals in Mathcad Prime:
  `[x; y] := odesolve([x; y], t, 10)` onder een Given-blok met `x'(t) == y(t)`, `y'(t) == -x(t)` en de beginwaarden.
- **Randwaardeproblemen**: voorwaarden in twee punten, bijvoorbeeld een ligger
  `w''''(x) == q/EI`, `w(0 m) == 0 m`, `w''(0 m) == 0`, `w(L) == 0 m`, `w''(L) == 0`, `w := odesolve(x, L)`.
- **Eenheden bij symbolisch rekenen (→)**: `F * a →` geeft `20 kN · m`, `1 m + 50 cm →` geeft `1.5 m`.
- Een kale `0` als voorwaarde past bij elke eenheid.
