## MathPrime 1.7.0

Installeer met `MathPrime-1.7.0-setup.exe` (sluit MathPrime eerst; je werkbladen en instellingen blijven staan).
Zonder installatie: pak de zip uit en start `mathprime.exe`.

### Grafieken
- **3D-oppervlakken**: `plot x = -3 ; 3, y = -3 ; 3 : f(x, y)`; draaien door te slepen, dubbelklik zet de blik terug.
- **Hoogtelijnen**: hetzelfde met `| contour`.
- **Poolgrafieken**: `plot θ = 0 ; 2*π : 1 + cos(θ) | polar`.
- **Tweede y-as**: `plot t = 0 s ; 10 s : F(t) ; u(t) = kN ; mm` (na `;` de rechter as, met eigen eenheid).

### Rekenen
- **Symbolisch**: `→ limit, x = 0` (ook naar ∞), `→ series, x = 0, 5` (Taylor), `→ float, 4`, en integralen van
  sin, cos, exp, tan, sinh, cosh en machten van `a·x + b`, ook partieel (`x · eˣ`).
- **Radau** voor stijve differentiaalvergelijkingen (zelfde vorm als `rkfixed`).
- **Data-analyse**: `regress` en `loess` (met `interp`), `ksmooth`, `medsmooth`, `localmax`, `localmin`, `filterNaN`.

### Werken
- **Direct afdrukken** met Ctrl+P (PDF-export is nu Ctrl+Shift+P).
- **Sjablonen**: Bestand → Nieuw uit sjabloon (verslag, tentamen, ligger, warmtebalans).
- **Slepen** van regio's op het raster; ze vallen niet meer over elkaar, en blijven geselecteerd.
- **Engelse interface**: Instellingen → Taal.

### Verder
- MathPrime valt nu onder de MIT-licentie.
- Een grotere testset (12 testbladen met nagerekende uitkomsten) draait bij elke wijziging.
- Opgelost: `rkfixed` gaf `D` een getal in plaats van een vector bij één vergelijking met `[1]` als beginwaarde.
