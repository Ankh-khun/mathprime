## MathPrime 1.5.0

Installeer met `MathPrime-1.5.0-setup.exe` (sluit MathPrime eerst; je werkbladen en instellingen blijven staan).
Zonder installatie: pak de zip uit en start `mathprime.exe`.

### Nieuw sinds 1.2

**1.5**
- Melding rechtsonder als er een nieuwere versie is (eens per dag; uit te zetten in Instellingen → Updates).
- Tests en releases automatisch via GitHub Actions.

**1.4**
- Afdrukvoorbeeld (Ctrl+Alt+P): het blad precies zoals het in de PDF komt.
- Logaritmische assen en vaste asgrenzen in grafieken:
  `plot f = 10 Hz ; 100 kHz : abs(H(f)) | log xy` en `plot x = 0 ; 10 : sin(x) | y = -1 ; 1`.
- Ctrl+Alt+P startte ook de PDF-export (Ctrl+P); opgelost.

**1.3**
- Eén venster: een `.rkn` openen terwijl MathPrime al draait, opent een tabblad in dat venster.
- Elke minuut een kopie van gewijzigde bladen; na een crash vraagt MathPrime of die terug moeten.
- Zoeken (Ctrl+F), vervangen (Ctrl+H) en een variabele overal hernoemen ("Hele namen").
